# Salud 基幹システム 開発ロードマップ

> 更新日: 2026-10-08
> 本番: https://salud-admin-azure.vercel.app

## ✅ 稼働中の機能

| 機能 | 内容 |
|---|---|
| 顧客・案件・タスク管理 | 一覧・詳細・編集・削除・連絡先管理 |
| 受信トレイ | LINE受信の一覧・要返信フラグ・返信済み管理 |
| LINE連携 | 公式LINE「補助金の窓口」で受信、顧客の自動識別 |
| LINEから予定登録 | 「予定 7/10 14:00 山田製作所 打ち合わせ」で自動登録 |
| 毎朝のLINEダイジェスト | 毎朝 7:30 に今日の予定・期限タスク・要返信数を配信（`digest_enabled`で個別ON/OFF可） |
| Googleカレンダー同期 | 選択した仕事用カレンダーのみ自動同期。OAuth本番公開済み（7日失効リスク解消） |
| スケジュール画面 | 週表示・予定追加・Google同期・担当者ごとの色分け表示 |
| ダッシュボード | KPI・要返信・期限アラート・今日の予定 |
| 設定画面 | メンバー招待（アカウント作成＋初期パスワード発行）・パスワード変更・通知設定の保存 |
| 契約書作成 | ひな形に相手先情報を差し込んで契約書を作成・プレビュー・印刷/PDF化 |
| 請求書・見積書発行（2026-08-26） | Googleスプレッドシートのひな形を廃止し社内システムに統合。書類種別（請求書/見積書）タブ＋月別ナビゲーションで一覧管理、明細入力で小計・消費税・合計を自動計算、文書番号を`INV-YYYY-0001`/`EST-YYYY-0001`形式で自動採番、角印画像入りでプレビュー・印刷/PDF化・コピー、備考欄によく使う文面を複数保存して挿入可能 |
| 代理店ご紹介料管理（2026-10-08） | 案件に紹介元（代理店管理から選択／手入力）と紹介料を記録。紹介料=基本料金分(持続化1万・他2万)＋成功報酬額の2%、補助金の窓口は成功報酬額の50%、案件ごとに「紹介料なし」可。売上管理の「代理店ご紹介料」タブで、発生案件一覧・入金翌月払いの支払管理・代理店別実績を確認 |
| タスク候補の一括削除 | LINE検出タスク候補を一括却下 |
