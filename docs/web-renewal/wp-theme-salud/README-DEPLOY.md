# Salud WordPress テーマ — 導入手順

TOPデザイン案 v16（青×緑・One-Stop図解・SWOT診断連携・専門家7名）を
そのまま表示するフルスクラッチテーマです。

> ⚠️ **検索エンジンには非公開（noindex）の状態**で作ってあります。
> 中身を確認してOKになってから「本公開」に切り替えます（下の「本公開の手順」参照）。
> ⚠️ 現行サイトは残したまま、**テーマを「有効化」した瞬間に見た目が切り替わります**。
> いきなり有効化せず、まず「**ライブプレビュー**」で確認するのがおすすめです。

---

## 中身（ファイル構成）

| ファイル | 役割 |
|---|---|
| `style.css` | テーマ情報 + 全デザインのCSS |
| `header.php` | ページ上部（ロゴ・メニュー） |
| `footer.php` | ページ下部（フッター・追従ボタン・スクリプト） |
| `front-page.php` | トップページ本体（下層サンプル7枚も内包） |
| `index.php` | 予備テンプレート |
| `functions.php` | スタイル読込・カスタム投稿タイプ・AIO構造化データ・noindex制御 |
| `single.php` / `home.php` / `archive.php` / `page.php` / `search.php` / `404.php` | ブログ記事・一覧・固定ページ等 |
| `inc/customizer.php` | 管理画面から主要テキスト・連絡先を編集 |

## 更新のしやすさ（追加済み）

- **ブログ**: WordPress の「投稿 → 新規追加」で書くだけ。公開すると **TOPのブログ欄にも自動で最新4件が表示**されます。記事は見出し・表・箇条書きがサイトのデザインで自動整形（AIにも引用されやすい構造）。
  - 「設定 → 表示設定 → 投稿ページ」に固定ページ（例: ブログ）を割り当てると一覧ページになります。
  - 記事のカスタムフィールド `author_name` / `author_role` / `author_bio` / `author_image` を入れると「監修者」が表示されます（E-E-A-T / AIO対策）。
- **TOPのテキスト**: 「外観 → カスタマイズ」で、見出し・サブ文・電話番号・LINE URL・診断URL・SNS共有画像 をコード不要で編集できます（リアルタイムプレビュー付き）。

## インストール手順（WordPress管理画面から）

1. このフォルダを ZIP に固めた **`wp-theme-salud.zip`** を用意（同じ場所に生成済み）
2. WordPress管理画面 → **外観 → テーマ → 新規追加 → テーマのアップロード**
3. `wp-theme-salud.zip` を選択して **今すぐインストール**
4. **「ライブプレビュー」** をクリック（※まだ「有効化」しない）
   → 現行サイトはそのまま、新デザインを自分だけプレビューできます
5. 問題なければ **「有効化」** → 本番の見た目が新デザインに切り替わります

## 本公開（検索エンジンに載せる）の手順 ※確認OK後

1. `functions.php` の先頭付近にある
   ```php
   define( 'SALUD_NOINDEX', true );
   ```
   を `false` に変更（これで noindex 解除 + AIO構造化データが出力されます）
2. WordPress管理画面 → **設定 → 表示設定 →「検索エンジンでの表示」** の
   「検索エンジンがサイトをインデックスしないようにする」の**チェックを外す**
3. Google Search Console / Bing Webmaster にサイト登録 → サイトマップ送信

## この後の実装（フェーズ2・要相談）

現状は「承認デザインをそのまま表示する」段階です。運用しやすくするには:

- 各セクション（実績・専門家・料金・セミナー・ブログ）を**管理画面から編集可能**にする
  （カスタム投稿タイプは `functions.php` に登録済み。ACF等で紐付け）
- 問い合わせフォーム（Contact Form 7 等）の設置
- ヘッダーの「無料相談」「ログイン」ボタンのリンク先設定
- 下層ページ（制度別LP等）を独立ページ化 or 現行のハッシュ切替のまま運用するか決定
- AIO対策の仕上げ（記事テンプレ・監修者表記など。`docs/web-renewal/07-aio-seo.md` 参照）

## 補足

- 外部フォント・外部CDNは不使用（表示が速く、閲覧者の環境に依存しません）
- ロゴは Base64 でテーマに直接埋め込み済み（画像アップロード不要）
- 診断ボタンはすべて `https://hojokin-app.vercel.app/` に連携済み
- 公式LINE・電話番号・住所・認定支援機関ID は `functions.php` の `salud_opt()` に集約
