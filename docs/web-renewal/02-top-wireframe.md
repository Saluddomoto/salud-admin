作成日: 2026-07-07 / ステータス: 承認待ち

## 設計方針

- 「会社紹介サイト」→「営業・集客の中心」へ。TOPの役割は **信頼構築 → 興味喚起 → 診断/相談への送客**
- 参考: 補助金の窓口の導線（実績数値・無料相談多層CTA・LINE）× Apple/Stripe/Linear の余白と品位
- CTAは3種を使い分け: **① 30秒で無料診断**（最軽量・入口）/ **② 無料相談**（本命CV）/ **③ LINEで相談**（心理的ハードル最小）

## CTA配置マップ（指示書要件との対応）

| 指示書の配置指定 | 実装位置 |
|---|---|
| ファーストビュー | セクション1 メインCTA |
| サービス紹介 | セクション3直後の診断バンド（4） |
| 記事下 | ブログ記事テンプレートの記事下CTA（下層で実装） |
| サイドバー | ブログサイドバーCTA（下層で実装） |
| フッター | セクション12 診断リンク |
| お問い合わせ前 | セクション10 FAQ直後の最終CTA（11） |
| 固定CTA | モバイル下部バー + 右下LINEボタン |
