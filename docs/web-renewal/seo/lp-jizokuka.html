小規模事業者持続化補助金とは

小規模事業者持続化補助金は、小規模事業者が取り組む販路開拓・売上拡大・業務効率化の費用の一部を国が補助する制度です。補助上限は最大250万円、補助率は原則2/3。チラシ・Web広告・ホームページ制作・店舗改装・展示会出展・新商品開発など、幅広い使い道が認められているのが特長で、はじめて補助金に挑戦する事業者にも活用しやすい制度です。

対象になる主な経費

  • 広告・販促費（チラシ、ポスティング、Web広告、看板 など）
  • ウェブサイト関連費（集客用ホームページ・ネットショップの制作／改修）
  • 店舗改装・外装工事（来店促進のためのリニューアル）
  • 機械装置等費（業務効率化のための機器・設備の導入）
  • 展示会出展費・新商品の開発費 など

※公募回により対象経費・上限額・要件は変わります。最新の公募要領に沿ってご提案します。

Saludの持続化補助金サポート内容

「補助金が通るかどうか」は、事業計画書の完成度で大きく変わります。Saludは審査目線を熟知した専門家が、採択される計画書づくりを軸に、面倒な手続きをまるごと代行・伴走します。

  • 対象診断・活用プランのご提案（無料）
  • 事業計画書・補助事業計画の作成サポート（審査目線での添削）
  • 商工会議所／商工会の様式（事業支援計画書=様式4）取得のご案内
  • 電子申請（Jグランツ）の入力・提出サポート
  • 採択後の交付申請・実績報告まで伴走（もらい忘れ・返還リスクを防止）
  • 補助対象のホームページ制作・広告・集客までワンストップで対応

「申請したのに採択されなければ費用がかかる」という不安がないよう、Saludは成功報酬型を採用。不採択なら成功報酬はいただかず、同じ補助金の再申請も2回目まで無料でサポートします。

ご依頼の流れ

  1. 無料診断・お問い合わせ30秒の診断ツールまたはLINE・電話でご相談ください。
  2. ヒアリング・活用プランのご提案事業内容を伺い、対象経費と採択の可能性をご説明します。
  3. 事業計画書の作成サポート審査目線で計画書を作り込み、必要書類を整えます。
  4. 電子申請・提出Jグランツでの申請をサポート。提出まで伴走します。
  5. 採択・交付申請・実績報告採択後の手続きから補助金の受け取りまでフォローします。

よくあるご質問

個人事業主でも申請できますか？

はい。個人事業主も、常時使用する従業員数などの要件を満たせば対象です。開業間もない方もご相談ください。

ホームページ制作にも使えますか？

使えます。集客・販路開拓につながるサイトであればウェブサイト関連費として対象になり得ます。Saludは制作までワンストップで対応できます。

採択率はどのくらいですか？

公募回により変動しますが、事前準備と事業計画書の質で採択率は大きく変わります。当社は審査目線での計画書作成を支援し、事前確認130件超・採択率82%の実績があります。

費用はいつ発生しますか？

相談・診断は無料です。費用は原則、採択されたとき（成功報酬）に発生します。不採択の場合は成功報酬をいただきません。

申請にはどのくらい時間がかかりますか？

公募スケジュールにもよりますが、書類準備を含め数週間が目安です。締切から逆算して余裕を持ってご相談いただくと安心です。
