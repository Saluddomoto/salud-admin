How to read

凡例

各記事は「検索意図」「推定需要」「優先度」で分類しています。情報系で集客し、商用系（サービスLP）で相談に変える設計です。

検索意図（ファネル）

情報 制度を調べている段階（集客の入口）
比較 申請方法・やり方を探す段階
商用 依頼先を探す段階（相談に直結）

優先度

★★★ 最優先（需要大・CV貢献大）
★★★ 中（第2〜3陣）
★★★ 後回し（ロングテール）

推定需要

特大 / 大 検索者が多い主要KW
中 ニッチだが確度の高いKW
小 少数・ロングテール

Operating rules

1記事あたりの必須ルール ＆ 運用

量産しても「弱い記事」では順位が付きません。補助金は「お金＝YMYL」でGoogleが特に信頼性を厳しく見るため、全記事に以下を必ず入れます。

  • 実URL・1記事1キーワード・h1は1つ（SPAハッシュではなく個別ページ）
  • パンくず＋構造化データ（Article／FAQ／BreadcrumbList）でリッチ表示・AI検索対応
  • 監修者の明示（堂本さん等）＋公開日・更新日＋公式（一次情報）へのリンク＝E-E-A-T
  • 関連記事への内部リンク（クラスター内で回遊）＋記事末に相談導線（無料相談・LINE・電話）
  • アイキャッチ画像・図解で読みやすく（離脱防止）
  • 締切・公募回は月次で更新（鮮度が命）、GSCで順位・CTRを計測し伸び悩む記事をリライト
