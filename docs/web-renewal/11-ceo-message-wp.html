はじめまして。
株式会社Salud 代表取締役の堂本 拓央です。

私は金融機関で法人営業を経験した後、ITベンチャー企業でWebマーケティングやDXに携わり、その後、株式会社Saludを創業しました。創業以来、一貫して中小企業の成長支援に取り組んできました。

日本には優れた技術やサービスを持ちながらも、「資金」「人材」「情報」といった経営課題によって、新たな挑戦を諦めてしまう企業が数多く存在します。私たちは、そうした企業の挑戦を後押しする存在でありたいと考えています。

補助金は単なる資金調達の手段ではなく、企業の未来への投資です。

私たちは、補助金を活用した設備投資やDX推進、生成AIの導入支援を通じて、中小企業の生産性向上と持続的な成長を実現するパートナーとして伴走しています。

また、補助金申請の支援にとどまらず、ホームページ制作、Webマーケティング、SEO・MEO対策、SNS運用など、企業の集客や売上向上まで一貫してサポートしています。

私自身、ビーチテニスのプロ選手として国内外の大会に挑戦しています。スポーツを通じて培った「挑戦し続ける姿勢」と「最後まで諦めずにやり抜く力」は、経営にも通じる大切な価値観です。

お客様一社一社と真摯に向き合い、成果につながるご提案と伴走支援を続けることが、私たちの使命です。
