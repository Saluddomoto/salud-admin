## 優先順位（おすすめ着手順）

1. **本公開の前提**: テーマをライブプレビューで確認 → 有効化 → noindex解除
2. **AIO土台**: robots.txt + llms.txt + 構造化データ有効化（すぐ効く・低コスト）
3. **制度別LPの独立URL化**（SEOの最大の伸びしろ）
4. **問い合わせフォーム + 計測**（CVの取りこぼし防止）
5. **管理画面編集対応（ACF）**（運用の内製化＝5年続く土台）

各項目、既存デザインの上に「足す」だけで実現できます。
