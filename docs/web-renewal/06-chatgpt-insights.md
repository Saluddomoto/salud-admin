## 最終決定事項（会話の結論）

1. **メインコピー**: 「資金調達とWeb実装で、事業を前に進める。」
2. **サブコピー**: 「補助金は目的ではなく、手段。融資・補助金で資金を整え、Web・プロダクトを実装する会社です。」
3. **2事業部制**:
   - 資金調達事業部 = 融資支援 + 補助金申請支援 + 事業計画整理（**融資が入る！**）
   - WEB事業部 = Web制作・LP・集客導線設計・プロダクト初期実装
4. **やらないことを明記**: クラウドファンディング支援・VC/エクイティ調達支援はやらない。「補助金だけ」の相談は受けない
5. **選別思想**: 補助金"だけ"目的の層は自然に離脱させ、「事業を前に進めたい実行フェーズの会社」だけを集める
6. **診断の定義**: 「取れるか」ではなく「使えるか」を判断する診断
7. **AIは前に出さない**: 実装手段の一部として扱う（AI開発会社に見せない。将来分社できるURL設計だけ確保）
8. **支援の流れ**: 戦略・構想整理 → 資金調達設計 → 申請・実行支援 → Web・プロダクト実装
9. **言葉のルール**: ❌バッチリ/しっかり/全力/万全 → ⭕設計/整理/構築/実務/実行（硬質ワードで統一）
10. **デザイン**: クール/ミニマル。白背景・薄枠線・モノトーン+アクセント1色（**ネイビー or ダークグリーン**）
11. **HPの役割**: 売る場ではなく「相談していい会社」と思わせる信頼装置。無料診断＝集客エンジン
