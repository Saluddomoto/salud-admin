# salud-web.jp リニューアル ① サイトマップ / WordPress設計

作成日: 2026-07-07 / ステータス: 承認待ち

## コンセプト

- ブランド: **「中小企業の成長を支えるDXパートナー」**
- デザイン: Apple / Stripe / Linear / Notion 系。余白・高級感・シンプル・信頼・先進性
- 目的: 問い合わせ増・補助金相談増・HP制作/AI導入支援の受注増・信頼性/ブランド向上
- WordPress は継続利用。既存記事・SEO資産（URL・被リンク）は引き継ぐ

## サイトマップ

> 2026-07-07 更新: 壱市コンサルティング（11consul.com）の仕様を採用。

> カテゴリーごとに縦長LP を量産できるテンプレート構成にする。
> 各LPの構成: 悩み提起 → 特徴/強み → 実績・事例 → 料金 → 流れ → FAQ → CTA（診断/相談/LINE）

## グローバルナビ

`サービス / 導入事例 / セミナー / 補助金情報 / ブログ / 会社概要` + 右端に `ログイン`（顧客ポータル）と `無料相談` ボタン

## カスタム投稿タイプ（CPT）

| CPT | slug | 主なACFフィールド |
|---|---|---|
| 導入事例 | `works` | 会社名 / 業種 / 利用サービス（複数） / 補助金名 / 課題 / 施策 / 成果（数値） / お客様の声 / ロゴ・写真 |
| セミナー | `seminar` | 開催日時 / 形式（会場・オンライン） / 定員 / 料金 / 講師 / 申込URL or フォーム / ステータス（予定・終了） / アーカイブ動画URL |
| お客様の声 | `voice` | 会社名 / 業種 / 担当者名（任意） / 顔写真 / 本文 / 関連サービス / 星評価 |
| 補助金情報 | `hojokin` | 補助金名 / 上限額 / 補助率 / 締切日 / 対象者 / 公式URL / ステータス（公募中・終了） |
| お知らせ | `news` | 本文のみ（標準エディタ） |
| サービスLP | `service` | カテゴリー（補助金/Web・AI） / キャッチ / 悩みリスト / 特徴（繰り返し） / 上限額・補助率 / 料金 / 流れ（繰り返し） / FAQ（繰り返し） / 関連事例 — **LPテンプレートで管理画面から量産** |

タクソノミー: `works` → 業種・サービス種別、`blog` → 既存カテゴリ維持

## テーマオプション（ACF Options Page「サイト設定」）

誰でも管理画面から変更できる項目:

- **補助金診断ツールURL**（全CTAに反映）
- LINE友だち追加URL
- 電話番号 / メールアドレス / 営業時間
- 実績数値（支援件数・採択率など TOP に表示）
- 固定CTAの文言 ON/OFF
- Googleレビュー埋め込みコード / SNSリンク

## SEO資産の引き継ぎ

1. 既存記事は WordPress DB のまま維持（インポート不要）
2. パーマリンク変更が必要な場合のみ **301リダイレクト**（Redirection プラグイン）
3. タイトル・ディスクリプションは SEO SIMPLE PACK または Yoast を継続
4. XMLサイトマップ・構造化データ（Organization / FAQ / Article / Event）を出力
5. リニューアル前に Search Console の主要流入URLを控え、公開後に404監視

## 技術方針

- **クラシックテーマ + ACF Pro**（ブロックテーマより運用者に分かりやすい・要件のACF指定に合致）
- 子テーマではなくフルスクラッチのオリジナルテーマ `salud`
- CSS はビルド不要の単一設計（カスタムプロパティでトークン管理）、JS は最小限の vanilla
- 画像は WebP + `loading="lazy"`、LCP対象のヒーローのみ `fetchpriority="high"`
- Core Web Vitals: 外部フォントは `font-display: swap` + preload、CLS対策で寸法明示
- フォーム: Contact Form 7 or WPForms + reCAPTCHA v3
- 将来の Salud 連携: ヘッダー「ログイン」→ 顧客ポータルURL（テーマオプションで変更可）。AI議事録・AIチャット等はポータル側メニューに追従する想定で、サイト側はリンク差し替えのみで対応可能な構造にする
